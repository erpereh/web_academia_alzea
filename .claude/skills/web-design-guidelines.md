Review the current component or page and apply the following web design guidelines for Academia Alzea:

## Visual Hierarchy
- Headlines use Montserrat bold/semibold, body text uses Open Sans regular/medium
- Font size scale: 12/14/16/20/24/32/40/48/64px — never skip more than one step
- Limit each section to one primary CTA (call-to-action)
- Place the most important content in the top 600px (above the fold)

## Whitespace
- Section padding: `py-16 md:py-24` minimum
- Card inner padding: `p-6 md:p-8`
- Stack text elements with `space-y-4` or `space-y-6`
- Never crowd elements — whitespace builds trust for parents evaluating an academy

## Color Usage
- `#1E3A8A` (blue) — headings, nav, trusted/authoritative elements
- `#F59E0B` (orange) — highlights, badges, energy accents
- `#10B981` (green) — ALL primary CTAs, WhatsApp button, contact actions
- `#F8FAFC` (off-white) — page background
- Use blue and orange sparingly together; green only for action elements

## Accessibility
- Contrast ratio ≥ 4.5:1 for body text, ≥ 3:1 for large text
- All interactive elements have visible focus states (`focus-visible:ring-2`)
- Images include descriptive `alt` text
- Headings follow logical h1 > h2 > h3 order per page

## Conversion-Focused Layout
- Every section ends with or contains a CTA toward contact/WhatsApp
- Social proof (testimonials, years of experience, student count) near CTAs
- Phone numbers are `<a href="tel:...">` links on mobile
- WhatsApp link: `https://wa.me/34639070419`

Identify and fix any violations of these guidelines in the selected code.
